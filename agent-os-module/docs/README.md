# Dokumentacja OmniWatch

**Dokumenty aktywnego produktu:** [SPEC](../../docs/omniwatch/SPEC.md) i
[PLAN](../../docs/omniwatch/PLAN.md). Samodzielna aplikacja jest już wydana.

> **Priorytet produktowy, 2026-09-22:** dostarczenie OmniWatcha do analizy i researchu
> społeczności na Skool. [Kontekst i decyzje w lokalnym wiki](../../.omc/wiki/omniwatch-cel-i-spolecznosc.md).

Zacznij od [aktualnego stanu](STAN.md), potem przejdź do
[odłożonego szkicu zadań technicznych](ZADANIA.md).

- [Kontrakt danych](IR-CONTRACT-V2.md) — struktura formatu i odpowiedzialność instrumentów.
- [Pomiary i bramki](GRAPH-PLAN.md) — uzasadnienie architektury i historia eksperymentów.
- [Wiki lokalne](../../.omc/wiki/index.md) — wiedza projektu, poza Gitem.
- [Instrukcja klonowania](../CLONING.md) — opis istniejących mechanizmów.
- [Raport ekstrakcji](../test/eval/EVAL-TEXT.md) i [raport generowania](../test/eval/EVAL-GENERATE.md)
  — wyniki zapisanych przebiegów; daty znajdują się w raportach.

`STATUS.md`, `PLAN.md`, `PLAN-CLONE-V2.md` i obie kopie handoffu są historyczne.
`DESIGN.md` opisuje szerszy produkt. ZADANIA jest materiałem pomocniczym; priorytety całego projektu pozostają do ustalenia.
