OmniWatch pomaga zrozumieć jeden film bez oglądania, zdobywać wiedzę i być na bieżąco.
Samodzielna aplikacja jest już wydana. Teraz priorytetem jest wersja Agent OS. Scout to cykliczny
wyzwalacz tej samej funkcji. Agent OS i aplikacja samodzielna to dwie powłoki
jednego produktu, które docelowo używają wspólnego rdzenia. Nie muszą udostępniać
identycznego zakresu funkcji. Biblioteka Agent OS korzysta z jego pamięci; zakres
pamięci, kanałów i eksportu ZIP w płatnej chmurze pozostaje otwarty.

Dokumenty w `agent-os-module/docs/` dotyczą głównie osobnego, odłożonego projektu
tworzenia filmów na podstawie formatów. Jego wyniki nie są statusem tego wydania.
